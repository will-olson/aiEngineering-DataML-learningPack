# TLE API integration kit

Offline-friendly reference for the [TLE API](https://tle.ivanstanojevic.me/#/docs) used by Stanford Earth–Space feature sets **FS2** (State & Tracking) and **FS5** (Capstone).

| | |
|--|--|
| **Auth** | None |
| **HTTPS** | Yes |
| **CORS** | No (server-side / Python labs) |
| **Upstream** | https://tle.ivanstanojevic.me/ |
| **public-apis** | Science & Math → TLE |
