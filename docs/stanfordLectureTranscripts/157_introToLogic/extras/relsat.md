What is logical entailment? A sentence φ is consistent with a set of sentences Δ if and only if there exists a truth assignment that satisfies all the sentences in Δ ∪ {φ}. To show that a sentence is consistent with a supplied set of sentences, it suffices to find one truth assignment that satisfies all the supplied sentences.
