<p>The easiest way to solve this puzzle is to use Q1 to check the logic.</p>

<p>If Q1's answer was A, this tells us that Q2's answer is B, which tells us Q3's is D, which tells us Q4's answer is B, which tells us Q1's answer is C. A contradiction.</p>

<p>If Q1's answer was B, this tells us that Q2's answer is A, which tells us Q3's is C, which tells us Q4's answer is C, which tells us Q1's answer is A. A contradiction.</p>

<p>If Q1's answer was C, this tells us that Q2's answer is D, which tells us Q3's is A, which tells us Q4's answer is D, which tells us Q1's answer is B. A contradiction.</p>

<p>If Q1's answer was D, this tells us that Q2's answer is C, which tells us Q3's is B, which tells us Q4's answer is A, which tells us Q1's answer is D. Which is correct, and therefore the correct answer.</p>
