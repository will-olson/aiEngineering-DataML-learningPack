The following is a truth assignment for this language. p ( a ) i = 1 p ( b ) i = 0 q ( a , a ) i = 0 q ( a , b ) i = 1 q ( b , a ) i = 1 q ( b , b ) i = 0 Say whether each of the following sentences is true or false with this truth assignment. a. ∀ x .( p ( x ) ⇒ q ( x , x )) true false b. ∀ x .∃ y . q ( x , y ) true false c. ∃ y .∀ x . q ( x , y ) true false d. ∀ x .( p ( x ) ⇒ ∃ y . q ( x , y )) true false e. ∀ x . p ( x ) ⇒ ∃ y . q ( y , y ) true false | p ( a ) i = 1 p ( b ) i = 0 q ( a , a ) i = 0 q ( a , b ) i = 1 q ( b , a ) i = 1 q ( b , b ) i = 0 | a. | ∀ x .( p ( x ) ⇒ q ( x , x )) | true false |  | b. | ∀ x .∃ y . q ( x , y ) | true false |  | c. | ∃ y .∀ x . q ( x , y ) | true false |  | d. | ∀ x .( p ( x ) ⇒ ∃ y . q ( x , y )) | true false |  | e. | ∀ x . p ( x ) ⇒ ∃ y . q ( y , y ) | true false |  |
