| Logical equivalence, logical entailment, and logical consistency are related to each other in interesting ways, but they are not identical. If φ is equivalent to ψ, then φ is consistent with ψ. true false c. If φ entails ψ, then φ is equivalent to ψ. true false d. If φ entails ψ, then φ is consistent with ψ. true false e.
